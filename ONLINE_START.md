# BrainQuiz Studio 2.7 — Online starten

Die aktuelle **GitHub-Pages- und PeerJS-Version ohne Firebase** ist in [START_HIER.md](START_HIER.md) dokumentiert.

Für das bestehende Repository `bobxdd/Quiz`: ZIP entpacken, Projektdateien ins Repository-Root hochladen (mit `.github/workflows/pages.yml` und `docs/index.html`), danach GitHub Pages unter Settings → Pages auf GitHub Actions stellen.

Es werden **keine** Firebase-Variablen oder Datenbankregeln benötigt. Der Host-Browser muss während jeder laufenden Quizrunde verbunden bleiben.
